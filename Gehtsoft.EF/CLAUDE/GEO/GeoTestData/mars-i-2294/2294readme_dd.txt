Geologic Map of Science Study Area 1A, East Mangala Valles Region of Mars
Date of Publication: 1989

The following files are shapefiles and associated files that have been unprojected to decimal degrees from the original map projection.  
A shapefile in decimal degrees allows the user to project the file to his/her choice of projections.

i-1294.avl - ArcView legend

i-1294.met - Metadata information

i-1294.htm - Metadata information in HTML browser format

i-1294.txt - This file

i-1294_g.shp - Geologic contacts in ESRI shape file format

i-1294_s.shp - Structure in ESRI shape file format

i-1294.dbf - Dbase 4 tabular data for the shapefile

i-1294.shx - File connects the *.shp and *.dbf 

i-1294_snap.gif - quick-n-dirty snapshot of the map

NOTES:
-------------------------------------------------------
-The semi-major and semi-minor axis are defined.
-These maps are in projected meters (projection defined in
	metadata information).
-Mars coordinates are positive west. All of these files are
	saved in a positive east coordinate system because most
	GIS/remote sensing packages work in positive east coordinates
	(like Earth). Thus, you must negate all the longitude values if
	this file is reprojected from meters to decimal degrees.
-Nearly all of these maps were compiled on older photomosaic bases.
	There will be inconsistencies when using with newer bases.
